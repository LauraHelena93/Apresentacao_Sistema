# 👥Apresentação Sistema de Cadastro de Amigos 

> Sistema completo para gestão de amigos com autenticação segura e operações de CRUD, desenvolvido para simplificar o controlo e a organização de contactos.

---

## 📌 Sobre o Projeto

O **Sistema de Cadastro de Amigos** é uma apresentação desenvolvida com o objetivo de demonstrar a implementação de um fluxo completo de autenticação e gestão de dados. 

Para facilitar a compreensão do funcionamento do sistema, utilizamos a **analogia da biblioteca**:
- **Biblioteca:** O banco de dados do sistema[cite: 1].
- **Livros:** Os registos de cada amigo[cite: 1].
- **Ações da Biblioteca:** As operações fundamentais do CRUD (Criar, Ler, Atualizar e Excluir).

---

## 🚀 Funcionalidades

### 🔐 Sistema de Autenticação (Login)
- **Criação de Credenciais:** Registo seguro de utilizadores.
- **Validação de Dados:** Verificação de integridade antes da autenticação.
- **Autenticação:** Controle de acesso às rotas protegidas.
- **Sessão Segura:** Manutenção do estado de acesso do utilizador.

### 📝 Gestão de Amigos (CRUD)
- **Create (Criar):** Registo rápido de amigos com informações essenciais.
- **Read (Ler):** Visualização clara de todos os amigos numa lista organizada.
- **Update (Atualizar):** Edição flexível dos dados e confirmação das alterações.
- **Delete (Excluir):** Remoção segura de registos com alerta de confirmação.
